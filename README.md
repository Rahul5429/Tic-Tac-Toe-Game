Tic Tac Toe Game 🎯

A simple web-based Tic Tac Toe game built with HTML, CSS, and JavaScript. Play against a friend locally with an intuitive UI and responsive design.

Features

2-player local gameplay

Winning detection with highlights

Reset game option

Responsive UI for desktop and mobile

How to Run

Download or clone the repository.

Open index.html in your browser.

Play and enjoy! 🎮
